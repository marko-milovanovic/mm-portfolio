# Portfolio starter

A single-page responsive portfolio inspired by the structure and interaction style of the reference portfolio.

## Files

- `index.html` — page structure and placeholder content
- `styles.css` — layout, responsive styling, hover effects and modal styling
- `script.js` — smooth anchor scrolling, animated mobile navigation, tabbed About section, reveal animations and app overlays

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Put these three files in the repository root.
3. Push to the `main` branch.
4. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
5. Save and open the generated GitHub Pages URL.

## Customize

Search for `Placeholder`, `Your Name`, `Company Name`, and `hello@example.com`.

For each app, edit the `projects` array in `script.js`. Replace the placeholder App Store URL with the real URL.

The project artwork is CSS-only so the starter works without external assets. Replace each `.app-image-*` block with real screenshots later if desired.
